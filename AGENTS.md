# Agent instructions

Read AGENTS.local.md for project-specific architecture, commands and constraints.
Inspect Git state before editing and preserve unrelated work. Use focused branches
and pull requests. Make small coherent changes, test changed behavior with native
tools, inspect the complete diff, and report actual verification and limitations.
Use GitHub Issues for actionable work. Respect branch protection and obtain
independent technical review before merging with owner authorization.
Never expose secrets, weaken security boundaries, deploy without authorization,
or discard unique local work. Use native search first and current official docs
when external API details matter. This file is a reusable starting point;
projects own their architecture, workflow and verification commands.
