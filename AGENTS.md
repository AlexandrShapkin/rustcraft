# Agent entrypoint

Read [.github/DEVELOPMENT_INTERFACE.md](.github/DEVELOPMENT_INTERFACE.md),
[docs/INDEX.md](docs/INDEX.md), then [AGENTS.local.md](AGENTS.local.md).
The interface is the single shared lifecycle policy, including releases,
distribution, release notes, hygiene, debt and GitHub governance.
This entrypoint is managed;
put project rules and native commands in AGENTS.local.md, never fork the lifecycle.
User instructions and stronger project constraints prevail; report conflicts and
stop only dependent work. These files grant no additional execution authority.
Engineering Kit contracts bundled under .engineering-kit/contract are frozen
legacy provenance, not a second active administrative policy. Kit skills are
reference material, not implicitly installed or executed.
