# Research notes

Commit project-authored conclusions here, not copied source material.

Good note topics include:

- movement and collision constants/feel;
- block interaction expectations;
- world generation observations;
- redstone-like behavior chosen for this project;
- legacy protocol/format findings;
- texture-atlas/resource conventions;
- intentional divergences from Beta 1.7.3.

A useful note states the question, sources inspected, conclusion, uncertainty and resulting project
decision. Keep quotations/code fragments minimal.
