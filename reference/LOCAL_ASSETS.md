# Local original assets

Original Minecraft Beta 1.7.3 assets are optional local research/runtime inputs and are not part of
RustCraft source or distributable artifacts. Keep an owner-supplied compatible terrain sheet at
`reference/assets/terrain.png` or pass its path with `RUSTCRAFT_TERRAIN_TEXTURE` for the current
first-party client. Full local packs may be placed at `reference/assets/vanilla-b1.7.3/` or
`reference/assets/vanilla-b1.7.3.zip` for research. These paths are ignored.

Do not add proprietary asset payloads to Git or public releases. The local README under
`reference/assets/` is not required; this policy file and `docs/REFERENCE_POLICY.md` are the durable
instructions.
