# Pull request and workspace closeout

Instruction-only; no merge, remote settings change, deployment or destructive operation is authorized by this skill. Verify complete diff, Issue scope, exact HEAD CI, independent technical review and explicit merge permissions separately. Inventory local worktrees, branches and generated files; check open/Draft PRs, active processes, dirty or untracked changes and recovery of commits. Delete only explicitly authorized, verified obsolete/reproducible assets. Never blanket clean or prune uncertain state. Report retained data and space actually measured.
